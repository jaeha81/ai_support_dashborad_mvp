# 2026 혁신 소상공인 AI 활용지원 템플릿 대시보드 MVP

## 실행
`2026_ai_support_dashboard_mvp.html` 파일을 Chrome, Edge, Safari 등 최신 브라우저로 엽니다.

## 포함 기능
- 신청 전 자격진단
- 업체·대표자·신청유형 입력
- AI 활용모델 및 KPI 설계
- 시장성·성장성·수행역량 작성
- 총사업비/정부지원금/자부담 계산
- 공식 서류평가 항목 기반 작성 준비도 시뮬레이션
- 제출서류 체크리스트
- 사업계획서 초안, Word 호환 문서, TXT, JSON 백업
- 브라우저 로컬 저장

## 주의
비공식 보조도구입니다. 최종 제출은 공식 공고문·신청서식·소상공인24 화면을 기준으로 대표자가 직접 확인해야 합니다.
